# 数据表查询能力总览

> **来源**：`tables/{库名}/{表名}.md` 中的 `description`（表描述）与 `use_cases`（使用场景）字段原文汇总，未做额外推断。
> **数据来源**：`生产环境客服问题常用数据库表收集.xlsx`，测试同学为解决客服问题整理的常用查询表，示例 SQL 为泛用写法。
> **用途**：客服排查问题时，按业务分类快速定位「哪张表能查什么数据」。

共 **84** 张表、**15** 个库、**10** 个业务分类。
一张表属于多个业务分类时，在各分类下都会列出。
